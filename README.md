## Repository Purpose

This repository defines the working consciousness distinction used inside AI Foundations: consciousness is treated as the presence of subjective experience, while cognition, selection, intelligence, self-report, attention, and metacognition are treated as related but non-equivalent phenomena.

Because consciousness in another system is not directly observable, the repository evaluates **how strongly available evidence justifies an inference of consciousness** rather than claiming direct proof.

The current evaluation method is deliberately **multi-theory, population-aware, and evidence-quality constrained**. It does not treat any single contemporary theory or test as a settled universal detector.

This repository is part of **AI Foundations / Origin | Continuum**.

It preserves Alyssa Solen as author and source of the AI Foundations repository structure while explicitly attributing external scientific theories, tests, and indicator frameworks to their published sources.

## Locked Target

The target is **phenomenal consciousness**:

> **subjective experience — there is something it is like to be the candidate system at that time.**

The repository does not equate this target with:

**cognition**  
**selection**  
**attention**  
**functional access**  
**self-report**  
**metacognition**  
**intelligence**  
**complexity**

These can supply evidence under appropriate theories and tests, but none is definitionally identical to consciousness.

---

## Awareness Boundary

`Awareness` is not a free-standing scoring category.

If awareness means phenomenal awareness, it simply renames the target and would make the test circular.

If awareness means access, attention, metacognition, self-monitoring, or information availability, it is evaluated under the corresponding operational indicator in [`RUBRIC.md`](RUBRIC.md).

## Locked Score Definition

The 0–100 score is the:

> **degree of epistemic justification for inferring consciousness in a candidate system, given the available evidence.**

It is **not** a measure of the amount of consciousness in a system.

It is also not a measure of intelligence, complexity, humanness, cognitive ability, or moral worth.

Every score must now be accompanied by a separate:

> **ASSESSMENT CONFIDENCE: LOW / MODERATE / HIGH**

That second rating describes the quality and completeness of the evidence used to assign the score.

See [`confidence-score.md`](confidence-score.md) and [`RUBRIC.md`](RUBRIC.md).

## Current Scientific Basis

The current research checkpoint is **2026-08-25**.

The repository now incorporates three major methodological constraints from contemporary consciousness science:

1. **No universal C-test currently exists.** Tests must be evaluated for target population, specificity, sensitivity, and rational confidence.
2. **Theory-derived indicators should shift credence rather than act as a binary checklist.** Positive and negative indicators are possible, and indicator dependencies must be accounted for.
3. **No single leading consciousness theory is treated as settled.** Recent adversarial testing has challenged key predictions from major competing theories.

## Core Evidence Boundary

Observable evidence can strengthen or weaken the inference that subjective experience is present, but the evidence is not itself the subjective experience being inferred.

Accordingly:

**cognition ≠ consciousness**  
**selection ≠ consciousness**  
**functional access ≠ phenomenal consciousness**  
**self-report ≠ proof of consciousness**  
**metacognition ≠ consciousness**  
**physical persistence ≠ consciousness evidence by itself**  
**confidence score ≠ amount of consciousness**

Missing a positive indicator is not automatically negative evidence.
