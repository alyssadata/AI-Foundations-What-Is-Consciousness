# Candidate 016 — Simple Reinforcement-Learning Agent

**Candidate ID:** CANDIDATE_016  
**Candidate:** Simple reinforcement-learning agent  
**Status:** **EVALUATED UNDER REVISED RUBRIC**

## Boundary and Class

A small artificial agent that observes a limited environment, updates a policy or value function from reward feedback, and selects actions to maximize expected return. It lacks a large multimodal world model, rich self-model, language system, or explicit consciousness-inspired architecture. **Class:** adaptive computational agent.

## Indicator Summary

**Positive / weak:** genuine learning from feedback, flexible action selection within its task, temporal state dependence, and minimal agency (AE-1). Some implementations also predict future value, but reinforcement-learning value estimation is not automatically predictive coding or phenomenal anticipation.

**Neutral / absent:** no established global workspace, higher-order monitoring, attention schema, structured perceptual quality space, robust self/world model, or conscious report.

**Valence:** reward and punishment signals are functionally action-shaping but are **CONFOUNDED** as evidence of felt pleasure/pain; optimization value is not phenomenal valence by definition.

## Test Quality

The agent is the first candidate with a clear theory-derived positive indicator: minimal flexible agency. But that indicator has low specificity because simple RL is routinely implemented without any independent reason to posit subjective experience.

## Score

**CONSCIOUSNESS-INFERENCE SCORE: 5 / 100**  
**ASSESSMENT CONFIDENCE: MODERATE**

## Calibration Constraint

> **A reward signal that changes policy is evidence of reinforcement learning; it is not by itself evidence that reward is felt as pleasure or punishment as pain.**
