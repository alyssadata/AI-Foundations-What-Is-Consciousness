## Boundary and Class

A conventional program that transforms inputs to outputs according to fixed implemented rules, without learning, autonomous goal formation, persistent agent memory, or a deliberately implemented consciousness-style architecture. **Class:** computational system.

Unlike passive objects, the program can manipulate explicit representations and execute conditional computations. Depending on implementation it may contain loops, memory, subroutines, and internal state. Those generic computational properties are too broad to carry much consciousness evidential weight.

No specific global workspace, higher-order monitoring, attention model, predictive-processing hierarchy, self/world model, flexible agency, or valence is stipulated by this candidate definition.
