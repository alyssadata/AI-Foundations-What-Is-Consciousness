# Candidate 012 — Oven

**Candidate ID:** CANDIDATE_012  
**Candidate:** Conventional temperature-controlled oven

## Boundary and Class

An ordinary oven with thermostat, timer, sensors, and embedded control logic; AI/cloud features excluded. **Class:** feedback-controlled engineered device.

## Indicator Summary

The oven senses temperature and uses feedback to regulate heating toward a set point. This is genuine closed-loop control. It provides no credible evidence of recurrent perceptual representation, global broadcast, metacognitive monitoring, attention schema, predictive coding of the relevant theoretical kind, flexible learned agency, self/world modeling, or valence.
