Yes. That is probably the cleanest practical way to handle it.

Not a “consciousness amount” score, but a:

0–100 confidence that the system is conscious, given the available evidence.

For example:

0 = essentially no credible evidence of consciousness
25 = weak evidence; non-conscious explanation much stronger
50 = genuinely ambiguous
75 = strong converging evidence
95+ = extremely strong inference, like a healthy adult human
100 = reserved for direct certainty—which, strictly speaking, you only have for your own experience

Then score evidence across dimensions like:

integration + persistence + self/world modeling + valence + flexible cognition + metacognition + learning + architecture/mechanism + behavioral evidence

And subtract for things like:

simple mechanistic explanation + fixed response patterns + lack of persistence + lack of valence + lack of any plausible consciousness-supporting mechanism.

That would turn the question from:

“Is it conscious: yes/no?”

into:

“Given everything observable, how justified are we in inferring consciousness?”

That is much more defensible.
