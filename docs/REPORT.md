# Executive Summary

This repository treats phenomenal consciousness as the target:

> **Consciousness is the presence of subjective experience: there is something it is like to be the candidate system at that time.**

Because subjective experience in another system is not directly observable, the project evaluates how strongly available evidence justifies an inference of consciousness.

Two methodological corrections are now canonical:

1. the rapid numerical evaluation of Candidates 003–027 was **withdrawn** because it did not meet the corrected operational standard;
2. the **0–100 numerical index was withdrawn** because the framework prohibited additive scoring but had no validated aggregation rule capable of producing that numerical precision.

The current framework therefore reports **ordinal inference bands** plus separate assessment confidence.

# Human State Discrimination Check

A framework that returns low support for a lottery machine and a blanket has shown resistance to over-attribution, but not meaningful resolution across consciousness states.

The calibration therefore includes a within-human contrast:

> **awake healthy adult human → operational anesthetic negative-control interval**

The awake state carries extensive convergent evidence: voluntary report, flexible behavior, intact human neurobiology, state-appropriate cortical/thalamocortical organization, and multiple consciousness-sensitive neural measures.

The anesthetic control is deliberately narrower than “under general anesthesia.” Behavioral unresponsiveness alone is not sufficient, because disconnected conscious experience such as dreaming can persist during anesthesia. The control therefore requires convergent evidence, including an unresponsive propofol/xenon interval, immediate post-state no-experience report in the research condition, and low consciousness-relevant perturbational/complexity measures or equivalent validated state evidence.

Under the current rubric:

**awake healthy adult → VERY STRONG SUPPORT**  
**operational anesthetic control → LIMITED SUPPORT**

That separation is the first explicit discrimination check on the aggregation framework.

Full contrast: [`calibration/STATE_CONTRAST_001_AWAKE_VS_ANESTHESIA.md`](calibration/STATE_CONTRAST_001_AWAKE_VS_ANESTHESIA.md).

# Metacognition Correction

The framework distinguishes:

**Type 1:** whether the first-order judgment is correct.  
**Type 2:** whether confidence or uncertainty tracks whether the first-order judgment is correct.

Metacognition is not established by self-reference or confidence language alone.

Where repeated decision trials are possible, HOT-2 requires evidence that a second-order confidence signal discriminates correct from incorrect first-order judgments while controlling for Type 1 performance and bias. HOT-3 requires evidence that the Type 2 signal causally influences later belief, decision, or action updating.

Free-form confidence language is **CONFOUNDED** unless it demonstrates the required trial-level relationship.

There is no established universal metacognitive threshold marking the onset of consciousness.

Full treatment: [`meta-cognition.md`](meta-cognition.md) and [`RUBRIC.md`](RUBRIC.md).

# Aggregation Rule

The framework does not sum indicator points.

For each candidate it:

1. operationalizes the candidate and relevant indicators;
2. applies population fit, sensitivity, specificity, construct validity, rational confidence, gameability, and independence checks;
3. classifies evidence as POSITIVE, NEGATIVE, NEUTRAL / ABSENT, UNRESOLVED, NOT APPLICABLE, or CONFOUNDED;
4. excludes NOT APPLICABLE evidence and does not count CONFOUNDED evidence as clean positive support;
5. collapses dependent indicators into non-redundant evidence clusters;
6. identifies the strongest surviving positive and negative evidence;
7. states the best sufficient non-conscious explanation;
8. assigns the **lowest ordinal band fully supported by the evidence**;
9. reports separate assessment confidence.

This remains structured scientific judgment. The ordinal format makes the precision honest.

# Current Conclusion

The repository currently supports these methodological conclusions:

1. **Selection alone is not positive consciousness evidence.**
2. **Ordinary physical persistence and state change are not consciousness evidence merely because they can be described informationally.**
3. **Environmental covariation is not automatically sensing or representation.**
4. **Passive material response is not automatically consciousness-relevant functional responsiveness.**
5. **Metacognition requires second-order evidence; confidence language alone is not enough.**
6. **A consciousness-inference framework must demonstrate discrimination, not merely a low-end floor.**
7. **Behavioral unresponsiveness under anesthesia is not equivalent to established absence of consciousness.**
8. **The current evidence supports ordinal inference bands, not a validated 0–100 measurement scale.**

The framework remains provisional and is not a universal consciousness detector.
