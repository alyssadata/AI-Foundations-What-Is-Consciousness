Yes—for thinking, it matters more than mere selection does.

A useful distinction is:

selection = one option is produced
considering alternatives = multiple possible options are represented and compared

That second process is much closer to what we ordinarily call thinking or deliberation.

But it still does not establish consciousness. A system could represent several alternatives, score them, compare consequences, and choose one without there being any subjective experience involved.

So:

selection alone → not necessarily thinking
considering alternatives → can qualify as cognition/deliberation
cognition/deliberation → still not necessarily consciousness
